# Lestoroer Godot Fork

Глобальные правила — `~/agent-config/shared/AGENTS.md`.
Карта отличий этой ветки от upstream — [FORK_NOTES.md](FORK_NOTES.md).
Реализацию смотри в коде.

## Изменения форка

- Изменённый участок отмечай комментарием `Fork(Lestoroer)`; у нового файла
  достаточно маркера в начале. Объяснение кода, когда оно нужно, пиши отдельно.
- В карте обновляй строку соответствующей возможности: где находится и что делает.
  Новая строка нужна для новой возможности, а не для каждой правки.
- Маркеры помогают искать изменения. Полноту проверяй через `git diff <upstream> HEAD`.

## Ветки

- `<minor>-base` — исходник upstream; напрямую в него не коммитят.
- `lestoroer/main` — общие изменения и движок Voxel Underworld.
- `interior-star/main` — общие изменения плюс Surface Cache GI для Interior Star.
  Игра собирается из этой ветки; коммит закреплён в её `tools/engine/engine.json`.
- В интеграционные ветки изменения попадают через `git merge --no-ff`.
  Для общих изменений создавай `lestoroer/feat-*` или `lestoroer/fix-*`,
  для Interior Star — `interior-star/feat-*` или `interior-star/fix-*`.
  Коммиты помечай `[Lestoroer]`.
- `lestoroer/main` вливается в `interior-star/main`; обратного слияния нет.
  Общий код проверяют в обеих играх, включая Quest для Voxel Underworld.
- Не делай rebase или force-push интеграционных веток. Сборки в Git не добавляй.

## Обновление upstream и сборка

1. Выбери точный коммит релиза upstream и сохрани текущие вершины веток тегами.
2. Обнови `<minor>-base`, влей её в `lestoroer/main`, затем — в `interior-star/main`.
   Конфликты проверяй по карте и коду. Сравнение с upstream должно содержать
   отличия форка; одного количества маркеров для проверки недостаточно.
3. При смене версии очисти объектники своей сборки, затем пересобери движок.
   Повседневная сборка — без `dev_build=yes`; проверь версию готового бинарника.
4. Сборка и закрепление движка Interior Star — по [инструкции игры](../is-game/docs/run/README.md).
   После изменений рендера используй проверки [освещения](../is-game/game/features/lighting/README.md#проверки).
   Для Quest пересобери также Android templates с модулями проекта Voxel Underworld.
